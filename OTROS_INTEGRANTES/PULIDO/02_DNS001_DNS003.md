### PREGUNTA DNS1 · Demuestre DNS
**🗣️ ORAL:** "DNS001 resuelve los nombres internos, por ejemplo mail apunta a DKR002, y reenvía lo externo a Azure DNS. DNS003 simula la vista autoritativa externa con la IP pública del balanceador; lo público real lo administra DuckDNS."

**🖥️** `[DKR001]` · **⌨️ (🟢):**
```bash
sudo docker exec SRVD1DEVDNS001 named-checkconf
dig @10.1.100.41 mail.langustino-lab.duckdns.org A +short           # 10.1.100.102
dig @10.1.100.41 google.com A +short                                 # IP pública
dig @10.1.100.41 -p 5353 langustino-lab.duckdns.org SOA +short
dig @10.1.100.41 -p 5353 langustino-lab.duckdns.org NS +short        # ns1.langustino-lab.duckdns.org
dig @10.1.100.41 -p 5353 www.langustino-lab.duckdns.org A +short     # 172.212.220.169
dig @1.1.1.1 langustino-lab.duckdns.org A +short                     # 172.212.220.169 (DuckDNS)
```

**📌** ✅ · `dig @10.1.100.41 _ldap._tcp.dc._msdcs.langustino.local SRV` → ⏳ (sin reenvío condicional).
